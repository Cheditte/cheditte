# Profile artwork

The portrait cover uses the public halftone portrait and typography from [Ali Emre’s portfolio](https://aliemrealtuntas.com/). The gallery illustrations in `projects/` are the same project artwork used on the corresponding portfolio pages. They illustrate workflows. Each card links to the project walkthrough and its screens.

The Netgsm cover comes from [the original public project](https://github.com/Cheditte/abap-sms-netgsm/blob/a3d38832c932991b4286fdc02f43bc72a6a5b713/docs/img/abap-sms-netgsm-cover.jpg).

The earlier profile and TCMB banners are retained here for existing links. Their original generation notes are in [prompts.json](prompts.json).
