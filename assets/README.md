# Profile illustrations

The profile and TCMB banners use the Cheditte plum, cream and lime visual style. Both are 1920 × 640 PNGs, generated with OpenAI image_gen using the owner-supplied SAP logo as a reference. Prompts are recorded in [prompts.json](prompts.json).

These are explanatory illustrations, not SAP screenshots or an endorsement by SAP. The SAP mark remains associated with its owner. Generated originals are retained outside the repository; exported images are resized for the profile.
